# projeto_Elemental_Rush
Projeto do 2º período de Ciência da Computação da Cesar School, na disciplina de Programação Imperativa e Funcional, com o objetivo de aplicar, na prática, os conceitos aprendidos por meio do desenvolvimento de um casual game em linha de comando. O jogo inclui animações, movimentação dos elementos na tela e tratamento de colisões.
